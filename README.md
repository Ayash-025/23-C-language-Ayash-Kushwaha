## 🗂️ Repository Structure
The programs here are organized by concepts to make navigation easy:
- **01_Basics:** Syntax, Data Types, and Operators
- **02_Control_Flow:** If-else logic, Switch cases, and Loops (For, While, Do-While)
- **03_Functions:** User-defined functions, Scope, and Recursion
- **04_Arrays_and_Strings:** 1D/2D Arrays and string manipulations
- **05_Pointers:** Pointer arithmetic and memory management
- **06_Structures:** Structs, Unions, and Custom data types
- **07_File_Handling:** Reading, writing, and appending files
